# Прогнозирование оттока клиентов сервиса доставки кофе

Код и аналитика для проекта по прогнозированию оттока клиентов сервиса доставки кофе. Основной рабочий файл — Jupyter Notebook с полным пайплайном: от EDA и предобработки до обучения и сохранения финальной модели.

**Ключевые результаты**
- Модель: логистическая регрессия с L1-регуляризацией.
- Основная метрика: PR-AUC = 0.683 (тестовое), Log Loss = 0.123 (тестовое).
- Сохранённый пайплайн: `churn_detection.joblib` (создаётся в ноутбуке).

**Файлы**
- [Модель для прогнозирования оттока клиентов для сервиса доставки кофе.ipynb](Модель%20для%20прогнозирования%20оттока%20клиентов%20для%20сервиса%20доставки%20кофе.ipynb) — основной ноутбук с кодом и анализом.
- `churn_detection.joblib` — финальная сохранённая модель (генерируется ноутбуком при выполнении).

## Быстрый старт
1. Клонировать репозиторий или поместить файлы в рабочую папку.
2. Создать виртуальное окружение и установить зависимости:

```bash
python -m venv venv
source venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

Если файл `requirements.txt` отсутствует, установите библиотеки вручную:

```bash
pip install numpy pandas matplotlib seaborn phik missingno joblib python-dotenv scikit-learn
```

3. Подготовить датасет. В ноутбуке ожидание пути к данным происходит через переменную окружения `DATASET_URL`. Установите её, например:

```bash
export DATASET_URL=/path/to/coffee_churn_dataset.csv
# или для macOS / Linux в одной команде:
DATASET_URL=/full/path/to/coffee_churn_dataset.csv jupyter lab
```

## Что делает ноутбук
- Загружает датасет `coffee_churn_dataset.csv` из `DATASET_URL`.
- Выполняет EDA: пропуски, дубликаты, корреляции, визуализации.
- Строит пайплайн предобработки (импутация, кодирование, масштабирование).
- Делает feature engineering (новые признаки, бинаризация, логарифмирование где уместно).
- Обучает модели: базовая `DummyClassifier` и `LogisticRegression`.
- Подбирает гиперпараметры через `GridSearchCV` с кросс-валидацией.
- Сохраняет финальный пайплайн в `churn_detection.joblib`.

## Зависимости
- Python 3.8+ (рекомендуется 3.10/3.11)
- numpy, pandas, matplotlib, seaborn, phik, missingno, joblib, python-dotenv
- scikit-learn
