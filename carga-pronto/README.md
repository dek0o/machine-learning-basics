# Прогнозирование задержек доставки CargaPronto

## Описание проекта
Данный проект направлен на построение модели бинарной классификации, которая на основе данных о заказе и профиле клиента предсказывает риск задержки доставки (`late_delivery_risk`).

В рамках проекта проводится полноценный цикл анализа данных и машинного обучения:
1. Загрузка и проверка данных, устранение дубликатов и проблем со связностью.
2. Исследовательский анализ данных (EDA), оценка баланса классов и удаление географических аномалий.
3. Разделение выборки с использованием `GroupShuffleSplit` (для исключения пересечения клиентов между сплитами).
4. Обучение базовых моделей (Logistic Regression, CatBoost) и оценка качества по метрике ROC-AUC.
5. Кластеризация клиентов (KMeans) по географическим и поведенческим признакам.
6. Внедрение признаков кластеризации в модели машинного обучения и подбор лучшего количества кластеров.

## Структура проекта
- `Прогнозирование задержек доставки.ipynb` — основной Jupyter Notebook с ходом исследования, кодом обучения моделей и бизнес-выводами.
- `requirements.txt` — список необходимых Python-библиотек для запуска.
- `.env.example` — шаблон файла переменных окружения для безопасного хранения конфигураций.

## Данные
Проект использует два основных датасета:
- **Профили клиентов (`customers.csv`)**: содержит информацию о местоположении клиентов, количестве заказов, общей выручке, частоте возвратов и средних скидках.
- **История заказов (`orders.csv`)**: информация о заказах, стоимости товаров, типе доставки и целевом признаке `late_delivery_risk`.

> Данные подгружаются в проект динамически с использованием переменных окружения (`CUSTOMERS_DATASET`, `ORDERS_DATASET`).

## Установка и запуск

1. Перейдите в папку с проектом.
2. Рекомендуется создать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте конфигурационный файл `.env` на основе шаблона:
   ```bash
   cp .env.example .env
   ```
   Убедитесь, что в файле `.env` указаны корректные ссылки или пути к датасетам (в шаблоне прописаны демо-ссылки).
5. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook "Прогнозирование задержек доставки.ipynb"
   ```

## Краткие выводы
- В качестве лучшей модели для предсказания риска задержек выбран алгоритм **CatBoost**, показавший наиболее сильные и стабильные результаты качества по ROC-AUC.
- Выделение профилей клиентов с помощью кластеризации (географической и поведенческой) позволяет получить важные инсайты (например, выявить группу клиентов с аномально высоким `return_rate`), однако как самостоятельные признаки (фичи) для ML-модели они приносят лишь умеренное или незначительное улучшение прогноза. Кластеризация в данном кейсе более ценна для принятия управленческих решений, чем для буста качества предиктивной модели.
