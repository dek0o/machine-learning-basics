# Модель для предсказания массы морских черепах

**Автор:** Денис Куницын  
**Дата:** 1 марта

## Описание проекта

Этот проект представляет собой решение задачи машинного обучения для предсказания массы морских черепах на основе их физических параметров. Модель разработана для зеленых морских черепах (Chelonia mydas) и позволяет с высокой точностью определить вес черепахи по габаритам её тела.

## Цель проекта

Разработать функцию для предсказания массы морских черепах по их габаритам на основе модели машинного обучения.

## Задачи проекта

1. **Исследовательский анализ данных** — изучение предоставленного датасета, анализ распределения признаков и корреляций между ними.

2. **Предобработка данных** — очистка данных от пропусков, удаление дубликатов, обработка выбросов, масштабирование признаков.

3. **Обучение моделей** — тренировка нескольких моделей машинного обучения с различными гиперпараметрами:
   - LinearRegression
   - Ridge (с L2-регуляризацией)
   - Lasso (с L1-регуляризацией)
   - SGDRegressor

4. **Сравнение моделей** — оценка качества моделей на валидационной выборке по метрике MAE (средняя абсолютная ошибка).

5. **Проверка лучшей модели** — тестирование выбранной модели на тестовой выборке.

6. **Создание функции прогнозирования** — разработка функции для практического применения модели.

## Описание данных

Для анализа используется датасет `turtles.csv` со следующими признаками:

| Признак | Описание |
|---------|----------|
| `id` | Идентификатор измерения |
| `binomial_name` | Международное научное название вида черепахи |
| `registration_number` | Регистрационный номер черепахи |
| `shell_length` | Длина панциря, мм |
| `shell_width` | Ширина панциря, мм |
| `head_length` | Длина головы, мм |
| `head_width` | Ширина головы, мм |
| `flipper_length_n` | Длина ласты n (1-4), мм |
| `flipper_width_n` | Ширина ласты n (1-4), мм |
| `circle_count` | Количество колец роста на панцире |
| `measure_count` | Количество измерений по модели компьютерного зрения |
| `shell_crack` | Наличие трещин панциря |
| `timestamp` | Время внесения данных |
| `weight` | Масса черепахи, кг (целевая переменная) |

## Метрики качества

- **MAE** (Mean Absolute Error) — средняя абсолютная ошибка, основная метрика проекта
- **MSE** (Mean Squared Error) — среднеквадратичная ошибка
- **R2** (R-squared) — коэффициент детерминации
- **MAPE** (Mean Absolute Percentage Error) — средняя абсолютная процентная ошибка

## Результаты

Лучшая модель — **SGDRegressor** с параметрами:
- Регуляризация: L1 (Lasso)
- Функция потерь: squared_error
- Alpha: 1
- Шаг обучения (eta0): 0.001
- Тип данных: стандартизированные признаки

### Метрики лучшей модели на тестовой выборке

| Метрика | Значение |
|---------|----------|
| MAE | 3.23 кг |
| MSE | 19.87 |
| R² | 0.9832 |
| MAPE | 3.46% |

**Результат соответствует требованиям заказчика**: отклонение по MAE составляет менее 5 кг.

## Важность признаков

Наиболее важные признаки для предсказания веса черепахи:

1. **shell_length** (длина панциря) — наивысшая важность
2. **shell_width** (ширина панциря) — высокая важность
3. Габариты конечностей (лапы, голова) — средняя важность
4. **circle_count** (количество колец роста) — наименьшая важность
