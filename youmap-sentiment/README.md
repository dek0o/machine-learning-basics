# Анализ тональности отзывов с помощью нейросетей

## Описание проекта
Картографический сервис YouMap собирает отзывы о компаниях и организациях. Проект посвящён построению модели бинарной классификации на PyTorch, которая автоматически находит негативные отзывы (`target = 1`, оценка 1–2) для их приоритетной обработки командой качества.

В рамках проекта сравниваются два способа представить один и тот же текст для нейросети:
1. Исследовательский анализ данных: размер датасета, дисбаланс классов (≈ 9% негативных отзывов), пропуски.
2. Извлечение числовых признаков из текста (пунктуация, регистр, длина слов и др.) и стратифицированное разделение на выборки 70:15:15.
3. **Эксперимент 1:** несколько конфигураций MLP на числовых признаках с `BCEWithLogitsLoss(pos_weight)`, сравнение по PR-AUC и анализ кривых обучения.
4. **Эксперимент 2:** модель Embedding + masked mean pooling + MLP на индексах токенов с тем же разбиением и циклом обучения.
5. Анализ ошибок текстовой модели (FP и FN) и итоговое сравнение подходов.

## Структура проекта
- `Анализ тональности отзывов с помощью нейросетей.ipynb` — основной Jupyter Notebook с ходом исследования, экспериментами и выводами.
- `requirements.txt` — список необходимых Python-библиотек для запуска.

## Данные
Датасет `geo_reviews.csv` содержит тексты отзывов, федеральный округ, рубрики организации, готовые числовые признаки (длина отзыва, количество эмодзи, число рубрик) и целевой признак `target`.

> Путь к датасету задаётся переменной окружения `REVIEWS_DATASET`; по умолчанию ноутбук читает файл `datasets/geo_reviews.csv`. Веса обученных моделей сохраняются в папку `models/`, которая не хранится в репозитории.

## Установка и запуск

1. Перейдите в папку с проектом.
2. Рекомендуется создать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Положите датасет в `datasets/geo_reviews.csv` или укажите путь к нему в переменной окружения `REVIEWS_DATASET`.
5. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook "Анализ тональности отзывов с помощью нейросетей.ipynb"
   ```

## Краткие выводы
- Подход **Embedding + mean pooling + MLP** превзошёл MLP на числовых признаках по всем метрикам: на тестовой выборке PR-AUC **0.6304** против **0.3827**, ROC-AUC **0.9408** против **0.7291**, F1 **0.5995** против **0.3884** (recall 81.4% при precision 47.5%).
- Среди MLP на числовых признаках лучшей стала регуляризованная конфигурация `extra` (128, 64; Dropout 0.2; weight decay 1e-3): `Dropout` и `weight_decay` сгладили расхождение train и validation loss, но качество ограничено информативностью поверхностных признаков.
- Текстовая модель выучила лексику жалоб, но ошибается на смешанных и нейтральных отзывах и на нестандартных формулировках: mean pooling теряет порядок слов и отрицания. Следующий шаг — модели, учитывающие контекст (LSTM/GRU, CNN или предобученные трансформеры вроде ruBERT).
