# Рекомендательная система для книжного сервиса

## Описание проекта
Книжный сервис ReadMe (каталог около 500 книг) показывает всем пользователям на главной странице один и тот же блок «Популярное», из-за чего конверсия в чтение почти не растёт. Цель проекта — собрать пайплайн рекомендательной системы и обоснованно выбрать модель на замену популярному списку.

В рамках проекта:
1. Загрузка и проверка данных: типы, пропуски, дубликаты, корректность ключей между таблицами.
2. EDA: масштаб задачи, заполненность матрицы взаимодействий (~3.5%), распределения событий и оценок.
3. Временной сплит на train / validation / test с проверками отсутствия утечек и фильтрацией пользователей с тёплым стартом.
4. Реализация метрик precision@10, recall@10, MAP@10, NDCG@10 и coverage, единый формат предсказаний.
5. Построение и сравнение четырёх моделей:
   - **popularity baseline** — текущее решение сервиса;
   - **content-based** — профили книг из категорий (One-Hot), TF-IDF названий и описаний и года издания;
   - **item-based CF** — косинусное сходство книг по положительным взаимодействиям;
   - **ALS** (библиотека `implicit`) с подбором числа факторов на валидации.

## Структура проекта
- `Рекомендательная система для книжного сервиса.ipynb` — основной Jupyter Notebook с ходом исследования, моделями и выводами.
- `requirements.txt` — список необходимых Python-библиотек для запуска.

## Данные
Проект использует три таблицы:
- **Взаимодействия (`interactions.csv`)**: `user_id`, `item_id`, `rating` (1–5), `timestamp`.
- **Каталог книг (`items.csv`)**: `item_id`, `title`, `author`, `description`, `category`, `year`.
- **Пользователи (`users.csv`)**: `user_id`, `age_group`, `city`.

> Папка с данными задаётся переменной окружения `DATA_DIR`; по умолчанию ноутбук читает файлы из `datasets/`.

## Установка и запуск

1. Перейдите в папку с проектом.
2. Рекомендуется создать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Положите файлы `interactions.csv`, `items.csv` и `users.csv` в папку `datasets/` или укажите другую папку в переменной окружения `DATA_DIR`.
5. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook "Рекомендательная система для книжного сервиса.ipynb"
   ```

## Краткие выводы
- Лучший результат по основной метрике показала **item-based CF**: NDCG@10 = **0.2208**, что в 4.8 раза выше popularity baseline (0.0463).
- **ALS** (64 фактора, выбраны по validation) обходит baseline по всем метрикам точности (NDCG@10 = 0.1865) при coverage 0.962, но уступает item-based CF.
- **Content-based** задействует почти весь каталог (coverage 0.966), но по точности уступает даже baseline: в этих данных поведенческий сигнал оказался сильнее признаков содержания.
- Для продакшена рекомендована item-based CF: лучшая по NDCG@10 и при каталоге из 500 книг скорит весь каталог без отдельного этапа генерации кандидатов. Офлайн-оценка не измеряет реальную конверсию главной страницы, поэтому перед внедрением нужен A/B-тест.
