# Модель для прогнозирования вероятности клика на платформе рекламных аукционов

**Автор:** Куницын Денис

## Цель и задачи

**Бизнес-задача:** Оптимизация показа рекламы за счет точного предсказания того, кликнет ли пользователь по объявлению (оценка CTR).
**Цель:** Разработать модель бинарной классификации для прогнозирования вероятности клика на рекламное объявление.

**Задачи:**
1. Провести исследовательский анализ данных (EDA), выявить особенности распределений, обработать пропуски и выбросы.
2. Закодировать высококардинальные категориальные признаки (применение TargetEncoder).
3. Построить пайплайны обработки данных и провести отбор важных признаков.
4. Обучить базовые алгоритмы (LogisticRegression, SVM) и подобрать гиперпараметры.
5. Провести калибровку вероятностей (CalibratedClassifierCV) для финальной модели.
6. Сохранить артефакты для интеграции в продакшен.

## Данные

Данные подгружаются динамически с использованием переменных окружения. В датасете собраны параметры пользователя, рекламной кампании и контекст показа:
- Демографические данные, география, интересы пользователя.
- Тип устройства, время суток.
- Формат объявления, категория рекламодателя.
- Целевая переменная: факт клика по рекламе (бинарная).

## Установка и запуск

1. Установите необходимые зависимости из файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
2. При наличии `.env.example`, создайте свой файл `.env` и укажите в нём путь к вашим данным (например, `DATASET_URL`).
3. Запустите Jupyter Notebook `Предсказание вероятности клика.ipynb`.
