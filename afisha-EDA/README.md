# Анализ лояльности пользователей билетного сервиса

**Автор:** Денис Куницын

**Дата:** 15 февраля 2026

## Описание проекта

Исследовательский анализ данных пользователей билетного сервиса для определения профиля клиента, который с наибольшей вероятностью возвращается на платформу и совершает повторные заказы.

## Цель и задачи

### Цель
Исследовать профиль пользователя, который с наибольшей вероятностью возвращается на платформу и делает заказ повторно.

### Задачи
1. Выгрузить данные из базы и познакомиться с ними
2. Провести предобработку данных
3. Сформировать профиль пользователя
4. Провести исследовательский анализ данных
5. Дать общий вывод и рекомендации

## Данные

Для анализа использовались данные о заказах пользователей сервиса по продаже билетов.

### Описание датасета
- `user_id` — уникальный идентификатор пользователя
- `device_type_canonical` — тип устройства (mobile/desktop)
- `order_id` — уникальный идентификатор заказа
- `order_dt` — дата создания заказа
- `order_ts` — дата и время создания заказа
- `currency_code` — валюта оплаты
- `revenue` — выручка от заказа
- `tickets_count` — количество купленных билетов
- `days_since_prev` — количество дней от предыдущей покупки
- `event_id` — уникальный идентификатор мероприятия
- `service_name` — название билетного оператора
- `event_type_main` — основной тип мероприятия
- `region_name` — название региона
- `city_name` — название города

## Этапы анализа

### 1. Загрузка и знакомство с данными
- Подключение к базе данных PostgreSQL
- Выгрузка данных из таблиц: purchases, events, city, regions
- Первичный анализ структуры данных (290 611 строк, 15 столбцов)

### 2. Предобработка данных
- Приведение выручки к единой валюте (рубли РФ)
- Оптимизация типов данных
- Удаление дубликатов
- Фильтрация выбросов (99-й перцентиль по выручке)
- Удаление возвратов (отрицательная выручка)

### 3. Создание профиля пользователя
- Группировка данных по user_id
- Расчет метрик: количество заказов, средняя выручка, среднее количество билетов
- Создание бинарных признаков: is_two (2+ заказа), is_five (5+ заказов)

### 4. Исследовательский анализ данных
- Анализ признаков первого заказа
- Исследование связи выручки и состава заказа с повторными покупками
- Временной анализ (день недели, интервал между заказами)
- Корреляционный анализ (phi_k коэффициент)

## Ключевые результаты

### Статистика пользователей
- **20 755 уникальных пользователей** в выборке
- **60%** пользователей совершили 2+ заказа
- **25%** пользователей совершили 5+ заказов
- **Средний чек:** 545,7 рублей

### Факторы влияющие на возврат пользователей

| Фактор | Влияние |
|--------|---------|
| Количество билетов (2-3) | Высокая вероятность возврата (>70%) |
| Количество билетов (5+) | Низкая вероятность возврата (<20%) |
| Средняя выручка | Положительная корреляция с повторными покупками |
| День недели | Не влияет на удержание |
| Регион/Тип мероприятия | Слабое влияние |

### Корреляция с количеством заказов
Наиболее связанные признаки:
1. `avg_tickets_count` — среднее количество билетов
2. `tickets_segment` — сегмент по количеству билетов
3. `avg_revenue` — средняя выручка с заказа

## Рекомендации

1. **Сегмент 5+ билетов:** Скорее всего включает организованные группы (школьные классы, лагеря). Рекомендуется: скидки от 4 билетов или на каждый третий билет.

2. **Пользователи 2-4 заказа:** Возвращаются в ближайшие дни. Рекомендуется: разработка системы лояльности.

3. **Дополнительные исследования:** Влияние типа мероприятия на возврат пользователя.

4. **Инструменты привлечения:** Скидки в дни с наименьшей активностью пользователей.
