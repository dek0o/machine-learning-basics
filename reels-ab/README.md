# Разработка A/B-тестирования и анализ результатов

## Описание проекта
Развлекательное приложение с лентой коротких видео тестирует новый алгоритм рекомендаций, который учитывает персональные интересы пользователя и оптимизирован на глубокое вовлечение. Проект охватывает полный цикл A/B-теста — от анализа исторических данных и расчёта параметров эксперимента до мониторинга сплитования и проверки статистических гипотез.

В рамках проекта:
1. Исследовательский анализ исторических данных: динамика DAU и регистраций, распределение просмотренных страниц, доля успешных сессий (4 и более страниц).
2. Расчёт размера выборки (`statsmodels`, `NormalIndPower`) и длительности теста по среднему дневному трафику.
3. Мониторинг теста: баланс размеров групп, пересечения пользователей, распределение по устройствам и регионам.
4. Проверка гипотез по целевой метрике `good_session` (z-тест долей), прокси-метрике `page_counter` (критерий Манна–Уитни) и барьерной метрике `registration_flag`.

## Структура проекта
- `Разработка A-B-тестирования и анализ результатов.ipynb` — основной Jupyter Notebook с ходом исследования, расчётами и выводами.
- `requirements.txt` — список необходимых Python-библиотек для запуска.
- `.env.example` — шаблон файла переменных окружения со ссылками на датасеты.

## Данные
Проект использует три таблицы с сессиями пользователей одинаковой структуры:
- **Исторические данные (`sessions_history.csv`)**: сессии за период с 2025-08-15 по 2025-09-23.
- **Первый день теста (`sessions_test_part.csv`)**: данные за 2025-10-14, используются для мониторинга сплитования.
- **Полные результаты теста (`sessions_test.csv`)**: данные за период с 2025-10-14 по 2025-11-02.

> Данные подгружаются в проект динамически с использованием переменных окружения (`SESSIONS_HISTORY_DATASET`, `SESSIONS_TEST_PART_DATASET`, `SESSIONS_TEST_DATASET`).

## Установка и запуск

1. Перейдите в папку с проектом.
2. Рекомендуется создать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows используйте: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создайте конфигурационный файл `.env` на основе шаблона:
   ```bash
   cp .env.example .env
   ```
   Убедитесь, что в файле `.env` указаны корректные ссылки или пути к датасетам (в шаблоне прописаны демо-ссылки).
5. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook "Разработка A-B-тестирования и анализ результатов.ipynb"
   ```

## Краткие выводы
- Для обнаружения относительного эффекта 3% при базовой доле успешных сессий 30% (α = 0.05, мощность 0.8) необходимо **41 041** пользователь в каждой группе; при среднем трафике ~9 900 пользователей в день тест занимает около **9 дней**. В конце исторического периода наблюдается аномальное падение активности, поэтому оценка длительности ориентировочная.
- Сплитование корректно: разница размеров групп в первый день — **0.74%**, пересечений пользователей нет, распределения по устройствам и регионам совпадают.
- Целевая метрика не изменилась: доля успешных первых сессий — **31.57%** в группе A и **31.47%** в группе B (p-value = 0.8433). Прокси-метрика `page_counter` также без значимых изменений (p-value = 0.6242), барьерная метрика регистраций не нарушена (p-value = 0.2561).
- **Рекомендация:** не внедрять новый алгоритм рекомендаций — статистически значимого улучшения вовлечённости не обнаружено.
