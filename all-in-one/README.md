# Прогнозирование дефолта пользователя банка "Ва-банк"

## Описание проекта
Данный проект направлен на построение модели бинарной классификации, которая по историческим данным о клиентах оценивает вероятность дефолта в ближайшие 12 месяцев после даты скоринга. Решение этой задачи помогает банку минимизировать кредитные риски и оптимизировать процесс выдачи займов.

## Задачи проекта
1. Подготовка и объединение разнородных источников данных в единую таблицу наблюдений с учётом временной структуры.
2. Проведение исследовательского анализа данных (EDA).
3. Создание новых признаков, описывающих поведение клиента и его финансовую историю (Feature Engineering).
4. Разделение данных на обучающую, калибровочную и тестовую выборки с учётом фактора времени (Out-of-Time валидация).
5. Обучение и сравнение нескольких моделей машинного обучения (в т.ч. логистическая регрессия и случайный лес).
6. Подбор гиперпараметров лучшей модели и оценка её качества по метрикам классификации и бизнес-метрикам.
7. Проведение калибровки вероятностей.
8. Анализ матрицы ошибок и оценка устойчивости модели на калибровочных и тестовых данных.
9. Оценка важности признаков и формулирование выводов о факторах, влияющих на вероятность дефолта.

## Данные
В проекте используются данные о клиентах банка, их транзакциях, кредитной истории, макроэкономических показателях и дате скоринга.

Основные используемые датасеты:
- `loan_payment_credit.csv` — данные о просрочке платежа;
- `transactions.csv` — месячные транзакции клиента;
- `client_description.csv` — описание клиента на момент регистрации в банке;
- `credit_description.csv` — описание кредита;
- `mortgage_presence.csv` — данные о наличии ипотеки;
- `credit_rating.csv` — данные о кредитном рейтинге клиента;
- `macro_data.csv` — данные о макроэкономических показателях России;
- `cohort_grid.csv` — данные о дате проведения поведенческого скоринга.

## Структура проекта
В ноутбуке `Прогнозирование дефолта пользователя.ipynb` представлен полный пайплайн от загрузки данных до финальной оценки модели:
1. Загрузка необходимых библиотек
2. Загрузка данных
3. Исследовательский анализ данных
4. Объединение таблиц
5. Создание новых признаков
6. Анализ итоговой таблицы
7. Моделирование
8. Калибровка модели и пересчёт результатов
9. Поиск порога решения
10. Анализ матрицы ошибок
11. Фиксация итоговой модели
12. Анализ важности признаков
13. Отчет о проделанной работе и результаты

## Стек технологий
- **Python 3.12**
- **Библиотеки для анализа данных и машинного обучения:**
  - `pandas`, `numpy` (обработка данных)
  - `matplotlib`, `seaborn`, `phik` (визуализация и анализ корреляций)
  - `scikit-learn`, `imbalanced-learn` (построение пайплайнов, машинное обучение)
  - `mlxtend` (кросс-валидация для временных рядов)
  - `optuna` (подбор гиперпараметров)
- **Управление окружением и конфигурацией:**
  - `dotenv` (загрузка переменных окружения)
  - `joblib` (сохранение моделей)

## Установка и запуск

1. Установите зависимости:
   Вы можете установить их напрямую из сгенерированного в проекте файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения:
   Скопируйте пример файла конфигурации и укажите актуальные пути (или URL) к датасетам.
   ```bash
   cp .env.example .env
   ```

3. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook "Прогнозирование дефолта пользователя.ipynb"
   ```
