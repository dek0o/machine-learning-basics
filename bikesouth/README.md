# Прогнозирование спроса на велопрокат BikeSouth

## О проекте
Данный проект направлен на предсказание почасового спроса на аренду велосипедов. Точное прогнозирование позволяет оптимизировать логистику: своевременно пополнять станции велосипедами, избегать оттока клиентов из-за их нехватки и минимизировать простой техники. 

Проект выполнен с упором на внедрение лучшей инженерной практики (MLOps/Scikit-learn Pipelines), создание воспроизводимого процесса предобработки данных и построение легко масштабируемой отказоустойчивой модели.

---

## Бизнес-ценность
- **Цель:** Улучшить качество предсказания спроса по сравнению с существующей базовой моделью компании (Linear Regression), точность которой составляла $R^2 \approx 0.60$ со средней ошибкой (MAE) ~309 велосипедов.
- **Решение:** Разработана более сложная нелинейная модель, которая эффективнее улавливает скрытые паттерны (зависимость от погоды, времени суток и сезона).
- **Результат:** Финальная модель (kNN) стабильно превосходит базовую линейную модель по всем ключевым метрикам (RMSE, MAE, $R^2$). Пайплайн полностью готов к интеграции в production-среду компании для прогнозирования в реальном времени.

## Техническая реализация

### Стек технологий
* **Язык:** Python
* **ML/Утилиты:** Scikit-Learn, Optuna, Joblib, Pandas, NumPy
* **Визуализация:** Matplotlib, Seaborn, Phik

### Ключевые этапы и навыки
1. **Разведочный анализ (EDA) и Статистика:** 
   - Проведен анализ распределения целевой переменной с выявлением правосторонней асимметрии. 
   - Изучены взаимосвязи признаков с использованием матрицы корреляций. Удалены признаки, вызывающие мультиколлинеарность (например, показатель "точка росы", имевший $|corr| > 0.9$).
2. **Feature Engineering (Кастомные трансформеры):** 
   - Реализован ООП-подход: написан собственный класс `BikeFeatureEngineer` (наследующий `BaseEstimator`, `TransformerMixin`) для генерации новых признаков (логарифмирование радиации, осадков, расчет взаимодействий `Temp*Humidity` и `Wind*Visibility`). Это гарантирует отсутствие утечки данных (data leak) и легкую портируемость в production.
3. **ML Pipelines:** 
   - Вся логика преобразований (импутация пропусков, `StandardScaler` для числовых признаков, `OneHotEncoder` для категориальных) обернута в `Pipeline` и `ColumnTransformer`.
4. **Тюнинг гиперпараметров:** 
   - Подбор гиперпараметров алгоритма *k-Nearest Neighbors* осуществлялся через `GridSearchCV`.
   - Для комплексной модели *Decision Tree Regressor* применялась байесовская оптимизация гиперпараметров через **Optuna** (TPE Sampler) с механизмом ранней остановки (pruning).
5. **Оценка моделей:** 
   - Модели валидировались с использованием кросс-валидации (k-fold). kNN показал лучшую обобщающую способность и меньший разброс (std) метрик на фолдах по сравнению с решающим деревом.
6. **Вывод в Production:** 
   - Лучшая модель вместе со всем флоу преобразований данных сохранена через `joblib` (`knn_final_pipeline.pkl`), что позволяет применять функцию `.predict()` к сырым данным из источника.

## Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd bikesouth
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Для запуска пайплайна обучения и оценки откройте Jupyter Notebook:
   ```bash
   jupyter notebook "Прогнозирование спроса на велопрокат Bikesouth.ipynb"
   ```

*Примечание: для корректной работы потребуется добавить `.env` файл с переменными `TRAIN_DATASET_URL` и `TEST_DATASET_URL` или заменить их путями до локальных датасетов.*
