## 📂 Проекты

### [CargaPronto: Прогнозирование задержек доставки](./carga-pronto)
Проект посвящён разработке модели бинарной классификации для предсказания риска задержки доставки. Основной вызов состоял в корректной валидации: чтобы избежать утечки данных из-за пересечения истории одних и тех же пользователей, было применено разделение выборок с помощью `GroupShuffleSplit`. Дополнительно проведена поведенческая и географическая кластеризация клиентов с помощью алгоритма KMeans, что позволило выявить аномальные сегменты и извлечь ценные управленческие инсайты. Финальное решение построено на базе мощного градиентного бустинга CatBoost.

### [UrbanStay: Прогнозирование отмены бронирования](./hotels-churn)
В данном проекте решается задача бинарной классификации для раннего выявления бронирований с высоким риском отмены. Особенностью подхода стало объединение классических табличных параметров с текстовой информацией из предыдущих отзывов клиентов, для чего был использован алгоритм TF-IDF векторизации. Более того, выбор оптимального порога классификации основывался не на абстрактных ML-метриках, а на максимизации реальной бизнес-выгоды (Incremental Revenue). Данные извлекались и обрабатывались напрямую из СУБД PostgreSQL с использованием SQLAlchemy.

### [AutoValueAI: Предсказание стоимости автомобилей](./autovalueai)
Проект представляет собой регрессионную модель для оценки рыночной стоимости автомобилей, оптимизированную с учётом асимметричных бизнес-рисков (переплата и недооценка). В ходе работы проведено масштабное сравнение ведущих фреймворков градиентного бустинга — XGBoost, LightGBM и CatBoost. Выбор лучшего решения производился с балансировкой классической точности и минимизации доли убыточных для компании прогнозов. Для интерпретируемости результатов и понимания влияния каждого признака на итоговую цену применялся глубокий SHAP-анализ.

### [Ва-Банк: Прогнозирование дефолта пользователя](./all-in-one)
Построение скоринговой модели для оценки вероятности дефолта клиента банка на горизонте 12 месяцев. Проект отличается сложным этапом Feature Engineering: итоговый датасет собирался из восьми разнородных источников, объединяющих транзакции, кредитную историю и макроэкономические показатели. Для обеспечения устойчивости модели в условиях меняющейся экономики применялась строгая Out-of-Time валидация. Финальный пайплайн включает в себя не только предсказание, но и калибровку вероятностей, что позволяет банку точнее оценивать ожидаемые потери.

### [BikeSouth: Прогнозирование спроса на велопрокат](./bikesouth)
Задача предсказания почасового спроса на аренду городских велосипедов. Интересным инженерным решением стала реализация кастомного трансформера `BikeFeatureEngineer`, интегрированного в единый `Pipeline` совместно с `ColumnTransformer` для строгой и воспроизводимой обработки признаков. Благодаря эффективному подбору гиперпараметров с использованием байесовской оптимизации (Optuna с прунингом), удалось значительно превзойти базовую линейную модель с помощью алгоритма kNN.

### [Yeti: Предсказание возраста посетителей сайта](./yeti)
Разработка модели мультиклассовой классификации для определения одной из пяти возрастных категорий пользователей на основе их цифрового поведения. Успех решения обусловлен тщательным подходом к отбору признаков: использовались методы фильтрации по дисперсии (VarianceThreshold) и статистической значимости (SelectPercentile) внутри пайплайна. Проблема несбалансированности классов была эффективно решена с помощью взвешивания. Итоговая модель на базе алгоритма опорных векторов (SVC) выделена в самостоятельные артефакты, готовые к внедрению.

### [Advandex: Предсказание вероятности клика](./advandex)
Оптимизация показа рекламы на платформе аукционов за счёт прогнозирования вероятности клика пользователя (оценка CTR). Из-за наличия большого числа категориальных признаков с высокой кардинальностью был успешно применён метод Target Encoding с регуляризацией. Важной частью работы стала калибровка предсказанных вероятностей с помощью `CalibratedClassifierCV`, что критически важно для аукционов второй цены и вычисления ожидаемой ценности показа. Базовые алгоритмы (Логистическая регрессия и SVM) были интегрированы в пайплайны с полным циклом обработки данных.

### [Coffee-Churn: Прогнозирование оттока клиентов](./coffee-churn)
Модель бинарной классификации, созданная для удержания клиентов сервиса доставки кофе. Исследование строится на детальном разведочном анализе данных (EDA) с фокусом на выявление скрытых закономерностей в поведении уходящих пользователей. Для интерпретируемости и отсева шумовых факторов выбрана логистическая регрессия с L1-регуляризацией (Lasso). Итоговый пайплайн преобразования данных и сама модель сериализованы для дальнейшего использования маркетинговым отделом.

### [Turtles-Weight: Предсказание массы морских черепах](./turtles-weight)
Регрессионная модель для биологов, предсказывающая массу морских черепах на основе их физических габаритов (размеров панциря и ласт). Для обеспечения максимальной обобщающей способности при небольшом объёме данных были протестированы различные линейные алгоритмы с регуляризацией. Лучший результат показал SGDRegressor, позволивший достичь высокой точности, превосходящей строгие требования заказчика. Для удобства конечных пользователей реализована готовая для вызова функция `predict_turtle_weight()`.

### [Afisha-EDA: Анализ лояльности пользователей](./afisha-EDA)
Глубокий исследовательский анализ данных (EDA) аудитории билетного сервиса без применения предсказательных моделей. Основной фокус сделан на выявление поведенческого профиля лояльного клиента, который совершает повторные заказы. Работа демонстрирует уверенное владение SQL: сырые данные извлекались и агрегировались напрямую из PostgreSQL-базы посредством SQLAlchemy. Визуализация и корреляционный анализ помогли сформулировать конкретные гипотезы по улучшению стратегии удержания клиентов.
