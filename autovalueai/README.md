# Предсказание стоимости автомобилей с учетом бизнес-рисков

## Цель проекта
Разработать и сравнить модели машинного обучения для предсказания рыночной стоимости автомобилей с учетом бизнес-рисков переплаты (Overpricing) и недооценки (Underpricing).

## Задачи
1. Провести экспресс-анализ данных (EDA) и изучить распределение целевой переменной.
2. Подготовить и предобработать данные для трех библиотек машинного обучения.
3. Обучить и сравнить модели XGBoost, CatBoost и LightGBM на стандартных настройках.
4. Рассчитать метрики качества (MAE, RMSE, R²) и бизнес-метрики (Overpricing Rate, Underpricing Loss).
5. Провести поиск гиперпараметров с помощью Optuna для оптимизации моделей.
6. Интерпретировать результаты через SHAP-анализ и выявить ключевые факторы влияния на цену.
7. Проанализировать ошибки модели в разрезе категорий (марки, регионы) и выявить зоны риска.
8. Провести финальную проверку лучшей модели на отложенной тестовой выборке.
9. Подготовить аналитическую записку с рекомендациями для бизнеса.

## Данные
Проект использует два датасета, доступных по URL, которые указываются в конфигурационном файле:
- **Обучающая выборка:** `train_data.csv`
- **Тестовая выборка:** `test_data.csv`

**Описание признаков:**
- `brand` - Марка автомобиля
- `make_year` - Год выпуска
- `mileage_kmpl` - Пробег (км)
- `engine_cc` - Объём двигателя (в куб. см)
- `fuel_type` - Тип топлива
- `transmission` - Тип коробки передач
- `owner_count` - Количество владельцев по ПТС
- `color` - Цвет автомобиля
- `service_history` - Наличие сервисной книжки
- `accidents_reported` - Количество зафиксированных ДТП
- `insurance_valid` - Действительна ли страховка
- `region` - Макрорегион РФ (Москва, Сибирь, Юг)
- `price_rub` - **Целевой признак** (Рыночная стоимость автомобиля в рублях)

## Выводы и финальный вердикт
1. **Рекомендованная модель:** CatBoost
2. **Точность оценки:** В среднем модель ошибается на 75,484 руб. Коэффициент детерминации равен 0.88, что подтверждает высокую надёжность прогнозов.
3. **Безопасность бюджета:** Риск опасной переплаты (Overpricing >20%) зафиксирован на уровне 13%. Это позволяет сохранять маржинальность при выкупе.
4. **Упущенная выгода:** Бизнес может терять до 20,110,819 руб. из-за занижения цены более чем на 20%. Рекомендуется ручной пересмотр для премиум-сегмента и редких моделей.
5. **Зоны риска:** Модель наиболее нестабильна в регионах Сибирь, СПб, Юг и Урал (доля ошибок >20%), а также на марках Toyota, Tesla, BMW, Volkswagen. Рекомендуется дообучение модели на региональных данных.
6. **Гиперпараметры для интеграции в мобильное приложение:**
    - `learning_rate`: 0.0401
    - `depth`: 4
    - `iterations`: 1906
    - `l2_leaf_reg`: 1
    - `loss_function`: MAE
    - `random_seed`: 42

**Финальный вердикт:** CatBoost обеспечивает оптимальный баланс между качеством предсказаний (MAE 79,368 руб. на тесте), управлением бизнес-рисками (13% переплат) и сохранением выручки. Модель готова к внедрению с рекомендацией по дополнительному контролю в выявленных зонах риска.

## Установка и запуск
1. Клонируйте репозиторий.
2. Создайте файл `.env` в корневой директории на основе `.env.example` и укажите ссылки на датасеты:
   ```bash
   cp .env.example .env
   ```
3. Установите необходимые зависимости из `requirements.txt`.
4. Запустите Jupyter Notebook `Предсказание стоимости автомобилей.ipynb`.
